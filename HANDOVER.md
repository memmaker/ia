- Tiles: one set, the game's own `installed_files/gfx/tiles/20x20/` (248 PNGs, one per `gfx::TileId`, map in `src/gfx.cpp` `s_tile_id_to_filename_map`; loader `io.cpp` `load_tile()`, black->magenta colour key + contour variant). - Coverage 100%: monsters 106/106 (`<tile>` in `data/monsters.xml`); items 135/135 displayable (every ItemType template or item sets `d.tile`; the 27 without are intrinsic attacks + `trap_spear`, never drawn); terrain 44/44 visible ids (data `d.tile` or a `tile()` override: Floor, Wall, Door, Trap, Pylon, Bridge, CrystalKey...; 4 `event_*` ids are invisible). Unknown grid = black; IA has no random-appearance tiles (potions/scrolls share one tile, colour by appearance).

- Enter menu: `GameCmd::cmd_menu` (Return in `to_cmd_default`, so standard + vi keys; controller-support mode keeps Return for moves, no menu there). `src/cmd_menu.cpp` / `include/cmd_menu.hpp`: `cmd_menu::run(title, entries)` = own `FloatMenu` State (overlay, box sized to longest entry/title + border + 1 space, centred, scrolls when taller than the screen; group headers unselectable; accelerators before cursor keys; Up/Down/Num8/Num2/PgUp/PgDn move, Enter/Num5/Num6 choose, Esc/Space/Num0/Num4/`.` cancel). `run_command_menu()`: groups as the manual (Gameplay / Convenience / Menus), keys by reverse lookup `game_commands::to_cmd()` over printable keys + Tab/Esc/F1/Num5/Num0 (current keyset), runs `game_commands::handle(cmd)`. No movement entries; Esc entry has no accelerator (Esc closes).
- Inventory (`BrowseInv` in `src/inventory_handling.cpp`, IA already had a cursor list): letter = main action at once (`ForceAutoSelect::yes`; equip/unequip/activate = game's own `on_selected()`), Shift+letter drop, Ctrl+letter examine, Enter/Space/Num5 = item menu (`rvip_item_menu`: e wield/wear/take off or a apply/use, t throw if throwable, d drop, v examine), Num+ main, Num- drop, Num* examine, Num0/`.` close. Drop/throw run through the game's `Drop`/`SelectThrow` states with a preselect (`s_rvip_preselect` item pointer -> `m_auto_select`, selected on first update). Examine = `popup::Popup` with `item->descr()`. After an action `s_rvip_reopen`; `actor_act.cpp` player act (before input) calls `inv_rvip::take_reopen()` and reopens `i` unless `actor::seen_foes()` is non-empty.
- Every item prompt (Apply, Drop, Throw, Equip, Identify) was already a cursor list in IA (MenuBrowser). No @-tags in IA.
- `io_input.cpp`: numpad + - * . finish reading input and their text event is skipped (`s_rvip_skip_text`, else `+`/`-` resized the window); Ctrl+letter keydown finishes reading, Ctrl taken from the event's `keysym.mod` (polled mod state is stale when events queue up).
